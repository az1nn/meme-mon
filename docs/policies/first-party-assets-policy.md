# First-party asset policy

Version: 1.0 — closed-beta policy
Scope: Mememom repository and closed-beta builds

The repository's [MIT code license](../../LICENSE) covers source code only. It
does not grant permission to reuse, redistribute, train on, upload, publish or
commercialize first-party artwork, generated images, logos, audio, names or
other non-code assets. This closed-beta policy is an explicit no-redistribution
restriction; it is not a public asset license.

Every first-party asset must appear in the [asset inventory](../art/asset-inventory.md)
with its origin, intended use, and an explicit license or release restriction.
An asset whose license field is `PENDING_OPERATOR_DECISION` is usable only in
the closed-beta build by the project operator; it is not evidence of a public
redistribution grant.

User-submitted media remains separate from first-party assets. A provenance or
rights declaration is not a transfer of ownership and does not make media
eligible for Canon publication. MM-07 and MM-08 remain the only moderation and
Canon authorities.

Before public distribution, the operator must replace every pending license
entry with a selected license or an explicit no-redistribution restriction and
record the decision in the inventory. Missing or conflicting inventory data is
a release blocker.
