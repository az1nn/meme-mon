# Contribuindo para Mememom

Mememom usa desenvolvimento orientado a especificação. Antes de abrir uma mudança de produto, adicione ou atualize a especificação, o plano e as tarefas correspondentes em `docs/`.

## DCO

Ao assinar um commit com `git commit -s`, você declara que tem o direito de contribuir o código e o submete sob a licença MIT deste repositório. Use, por exemplo:

```bash
git commit -s -m "feat: descrição da mudança"
```

Não envie imagens, memes, áudio ou outros materiais de terceiros ao repositório sem autorização explícita e verificável. Código MIT não licencia conteúdo de terceiros.

## Regras de contribuição

- Preserve Godot como o único runtime de cliente/renderização.
- Mantenha regras competitivas determinísticas fora da UI.
- Não promova Sandbox para Canon, deck competitivo ou partida online fora dos gates MM-07/MM-08.
- Inclua testes e evidência de verificação proporcionais à mudança.
- Reporte vulnerabilidades conforme [SECURITY.md](SECURITY.md), não em issue pública.
