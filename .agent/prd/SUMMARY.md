# Mememom Ralph Context

Mememom is a Godot 4.7.2 open-source meme TCG. Godot is the only client and
rendering runtime. Competitive rules are deterministic, versioned and kept in
domain services outside the UI. Sandbox content must not silently become Canon.

The authoritative project sources are `.specify/memory/constitution.md`,
`docs/ROADMAP.md`, `docs/plans/`, `docs/tasks/` and the exact live Git state.

Validation baseline:

```bash
npm test
```

The release remains closed beta while browser/device, visual/accessibility,
licensing, security, provider and operator gates are pending.
